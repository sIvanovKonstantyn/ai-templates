# Onboard

Read and follow the procedure file. Do not implement a product feature.

- In the kit: `../../pipeline/onboard.md` relative to this skill file.
- After install: `PROCEDURE.md` in this directory.

The kit root is `spec-ide/templates` when this workspace contains that directory. Commit `.spec`. Do not add `.spec/` to `.gitignore`.
